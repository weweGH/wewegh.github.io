Project Case Study

Overview

Title 원료 첨부파일 검색 RAG
Period 2025.04.09 — 2025.11.21
Tech Stack RAG, Semantic Search, Python
Core Value R&D 생산성 혁신
01. Background & Challenge

비효율적인 문서 확인 프로세스

연구원과 규제 담당자들이 성분 검토 시 수많은 PDF를 개별적으로 열람해야 하는 상황이었습니다. 이는 단순한 불편을 넘어 의사결정 지연과 중복 검토라는 심각한 R&D 생산성 저하로 이어지고 있었습니다.

02. User Insight

사용자는 '맥락'을 원한다

검색 로그 분석을 통해 결정적인 인사이트를 얻었습니다. 사용자는 '정확한 파일' 그 자체보다 "이 성분이 우리 규제에 적합한가?"에 대한 요약된 답변과 맥락을 파악하는 데 훨씬 많은 시간을 쓰고 있었습니다.

03. Solution: RAG System

지능형 시멘틱 검색 도입

단순 검색을 넘어, 의사결정에 필요한 정보를 자동 요약·맥락화하는 RAG(Retrieval-Augmented Generation) 접근 방식을 선택했습니다.

Key Result: 시멘틱 서치를 통해 사용자의 검색 의도를 파악하고, 최적의 규제 대응 정보를 즉각 제공합니다.
04. Final Learning

기술보다 중요한 '사용자 목적'

이 프로젝트를 통해 중요한 것은 기술적 성능이 아니라 "사용자가 어떤 결정을 내리기 위해 이 도구를 사용하는가"를 집요하게 파고드는 태도임을 배웠습니다.
