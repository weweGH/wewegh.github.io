원료 첨부파일 검색 RAG

수백 개의 규제 PDF를 열람해야만 의사결정을 내릴 수 있는 현실에서, 검색 자체가 아니라 “맥락 획득”이 문제라는 관점을 세우고 시멘틱 서치 기반 RAG로 해결했습니다.

기간

2025.04.09 ~ 2025.11.21

역할

문제 정의 · 사용자 리서치 · 정보구조 설계 · 시멘틱 서치/RAG 파이프라인 설계

스택

Python · 벡터 임베딩 · Semantic Search · Retrieval-Augmented Generation

Context

연구원·규제 담당자는 필요한 성분 정보를 찾기 위해 모든 PDF를 열어봐야 했고, 결정 근거를 확보하는 데만 시간이 소모되었습니다.

Decision

검색 비용 증가는 의사결정 지연과 중복 검토로 직결되어 R&D 생산성과 규제 대응 속도를 갉아먹고 있었습니다.

Framing

사용자는 정확한 문서를 원하는가, 아니면 의사결정에 필요한 핵심 맥락을 원하는가? 우리는 두 번째 질문으로 문제를 재정의했습니다.

Insight

검색 로그·열람 패턴을 분석한 결과, 사용자는 문서 저장보다 성분 요약과 규제 맥락 파악에 시간을 쓰고 있었습니다. 정보 요약이 곧 가치였습니다.

Outcome

키워드 검색 최적화 대신 RAG를 선택했습니다. 시멘틱 서치로 문서를 추출하고, 생성형 모델이 규제 맥락을 재구성하도록 설계해 검색 라운드를 줄였습니다.

Learning

검색 문제의 핵심은 기술적 정확도가 아니라 사용자의 의사결정 단계를 이해하는 것임을 체득했고, 이후 모든 탐색 프로젝트에 같은 기준을 적용했습니다.
