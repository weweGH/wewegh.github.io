About Myself

안녕하세요. 데이터 사이언티스트 전가현입니다. 통계학을 전공하고, 데이터 분석가로서 더 깊은 교통 도메인 지식을 쌓기 위해 도시과학대학원에서 교통을 전공했습니다. 대학원에서 다양한 데이터를 다루며 학위 논문으로 이미지 데이터를 활용한 고속도로 이벤트 예측 딥러닝 모델을 개발했습니다. 한 가지 주제를 위해 대용량 데이터를 수집, 전처리부터 모델 개발, 평가까지 오랜 시간 연구한 경험은 데이터 분석가로서 자부심을 갖게 된 계기가 되었습니다. 다양한 정형/비정형 데이터 전처리와 분석 경험과 ML/DL 알고리즘을 활용한 예측 모델을 실제 서비스에 배포하며 쌓은 역량을 타 도메인에 적용하여 완성도 높은 결과를 이끌어낼 수 있습니다. 또한 적극적인 소통으로 협업하여 팀의 정해진 목표를 달성하기 위해 높은 시너지를 낼 수 있도록 기여하겠습니다.
